PlantWise: Teaching a Plant-Care Agent When to Act with Strands Decider 2B

Description (max 512 characters):
PlantWise is a beginner plant-care advisor that uses Strands Decider 2B to classify plant observations into water, sunlight, or inspect before Amazon Bedrock generates the reply. The decider runs at 6 seconds median latency, 3.2x faster than an LLM doing the same classification, with calibrated confidence so the agent asks a follow-up question instead of guessing when uncertain.
